# CCR v0.6.1 Acceptance

Scope: translate Anthropic mid-conversation tool availability changes without
forwarding control blocks as unsupported OpenAI system content. MCP-specific
tool references remain outside this release's translation boundary.
Unchecked items are not claims of completed verification.

## Known Limits

Only simple `tool_reference` changes are translated. `mcp_tool_reference` and
`mcp_toolset_reference` are rejected visibly because an OpenAI-compatible
provider cannot be given a safe one-to-one mapping from those references.
Provider capability validation and no-silent-fallback behavior remain active.
