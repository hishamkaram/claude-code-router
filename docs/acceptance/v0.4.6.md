# CCR v0.4.6 Acceptance Criteria

This release fixes image-bearing Anthropic `tool_result` content on
OpenAI-compatible Chat Completions routes. A checked item requires reproducible
evidence on the final release candidate; skipped live tests are not evidence.

## Behavior

- [x] Nested image blocks in Anthropic `tool_result` content are converted to
  OpenAI `image_url` parts instead of returning the previous 501 rejection.
- [x] Tool-result text remains in a contiguous OpenAI `tool` message sequence.
- [x] Image-only tool results retain a non-empty `[image output]` placeholder.
- [x] Extracted images are emitted in a trailing user message after all tool
  messages, preserving image and text order.
- [x] Existing image source validation, size limits, URL restrictions, and
  vision capability validation remain enforced.
- [x] A live Claude Code MCP image-tool test proves the behavior after an
  in-session `/model` switch to an OpenAI-compatible alias.
- [x] The live path produces the expected response and no 501 compatibility
  error.

## Privacy and Security

- [x] Image conversion reuses the existing resolver and does not log or persist
  image contents.
- [x] No provider secret handling, persistence, or authentication path changed.
