# CCR v0.4.2 Acceptance Criteria

This is the release source of truth for account-aware subscription status and
resumable pool rotation. A checked item requires reproduced evidence. Skipped
live tests and unsupported commands are not evidence.

## Account Truth

- [x] A subscription-pool launch status line shows the selected local
  `account=<name>` label and `limits=unknown`.
- [x] Explicit `--claude-account <name>` sends that label's stored OAuth token
  on model requests even when other account credentials are registered.
- [x] CCR does not query unsupported quota endpoints, parse shared Claude
  profile caches, or present another profile's usage as selected-account data.
- [x] An existing user status line is replaced only in launch-generated
  settings, the launch records `statusline_state=replaced`, and user settings
  files remain byte-for-byte unchanged.
- [x] `--no-statusline` remains an explicit opt-out and warns that external or
  Claude-provided limits may belong to another local profile.
- [x] OAuth tokens and observer tokens are absent from CLI output and SQLite.

## Pool Rotation

- [x] Plain interactive pool launches rotate to the next account with
  `--continue` only after confirmed first-party subscription exhaustion.
- [x] Interactive `--resume <session-id>` launches, optionally combined with a
  named `--worktree`, rotate while replaying the original continuity arguments.
- [x] Launch output states whether automatic rotation is enabled and explains
  why it is disabled.
- [x] `--print`, explicit account selection, managed CUA, prompts, malformed
  resume/worktree arguments, and unknown passthrough shapes do not rotate.
- [x] Claude CLI, resume, worktree, settings, and process errors remain visible
  and never cycle through unrelated accounts.

## Evidence

Verified locally on 2026-07-25:

- Two separately registered accounts completed pinned real native Claude
  requests without exposing credentials.
- A real unpinned native Sonnet launch selected an already exhausted
  `account-3`, received Anthropic `HTTP 429 status=rejected`, and relaunched the
  preserved conversation on `account-1`. Confirmed exhaustion then rotated to
  `account-2`; the command exited only after all three accounts returned the
  same confirmed exhaustion state.
- `ccr claude-account list` showed only the three rejected accounts in cooldown.
  Redacted trace events `1011`, `1015`-`1020` recorded native Sonnet HTTP 429
  rejections; no token value appeared in command output or SQLite.
- The deterministic real-Claude fixture passed first-party selection,
  confirmed-exhaustion relaunch, temporary-429 non-rotation, status-line
  replacement, settings preservation, and secret-redaction assertions. A
  separate disposable-Git fixture seeded a real session and proved that
  `--worktree <name> --resume <session-id>` reached `Welcome back!` before and
  after confirmed-exhaustion rotation with the original continuity arguments.
- The maintainability gate passed with zero hard violations. Refactoring this
  feature reduced repository target warnings from 47 to 45; no touched
  production file exceeds the 600-line target.
- Unit, race, vet, lint, vulnerability, full live fixture, Docker CUA, macOS
  protocol fixture, release configuration, snapshot archive, action lint, and
  whitespace gates passed. `golangci-lint` reported zero issues and
  `govulncheck` found no vulnerabilities.
- The exact uncommitted Codex review reported no actionable correctness issues;
  its independent test, race, vet, lint, and live-tag compilation checks passed.
- `CCR_LIVE_REAL_MATRIX=1 make test-live-matrix` remains unchecked. Its
  synthetic fixture phase passed, but the configured-provider phase starts
  with a native Sonnet parent under `--auth-mode preserve`; the machine's
  preserved Claude subscription was exhausted and exited before those
  workflows could complete. Successful GLM provider routes were present in the
  redacted trace, so this is recorded as unavailable first-party test
  authentication, not passing matrix evidence.
- Hosted CI, PR merge, tag, and publication remain pending.
