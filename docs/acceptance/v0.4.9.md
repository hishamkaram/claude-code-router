# CCR v0.4.9 Acceptance Criteria

This release restores reliable Claude Code compaction through OpenAI-compatible
Chat Completions providers. A checked item requires reproducible evidence on
the final release candidate; a skipped live test is not evidence.

## Behavior

- [x] Streamed Anthropic Messages requests preserve `stream: true` upstream.
- [x] OpenAI SSE text and tool-call fragments are assembled in order.
- [x] Terminal finish reasons and usage are preserved for Anthropic conversion.
- [x] Non-stream requests remain non-streaming and omit `stream_options`.
- [x] A provider that ignores streaming and returns JSON remains compatible.
- [x] Malformed, incomplete, oversized, and error-event streams fail visibly.
- [x] Provider stream errors retain existing secret redaction.
- [x] No ambiguous provider request is retried and no route fallback occurs.
- [x] A fixture that closes every buffered request reproduces the old EOF path
  and succeeds only when CCR requests upstream SSE.
- [x] Claude Code 2.1.260 manual `/compact` retains session state and reduces
  the next OpenAI provider payload.
- [x] Claude Code 2.1.260 `--autocompact 100k` retains session state and reduces
  the next OpenAI provider payload.
