## Idle Pool Correction

The full live suite passed (CLI 384.308s, jobs 14.922s). The next combined gate
passed its fixture stage (289.990s), but the real stage failed (857.670s):
Grok and every other tested alias passed except the Haiku 4.5 selection.
That request returned `http2: client connection lost`. Its preceding provider
route completed at 13:53:13.674568064 UTC; the Haiku request began at
13:53:48.134298708 and failed at 13:53:48.677721476, 35.003 seconds after
the prior route completed. A fresh actual CLI probe returned
`CCR_RELEASE_HAIKU_CHECK`. This is tracked separately in
[issue #73](https://github.com/hishamkaram/claude-code-router/issues/73).

A deterministic HTTP/2 fixture reproduced reuse of a connection whose idle
health probe had not been acknowledged. The existing 90-second pool policy
failed with the same connection-lost error. The correction caps gateway-owned
idle connections at 15 seconds, before the 20-second health probe begins,
while preserving shorter caller limits and active-stream pings. Caller-owned
clients are unchanged. This uses Go's standard
[idle connection policy](https://pkg.go.dev/net/http#Transport), not retries
or protocol fallback. The missing ACK's external cause is not established.

The corrected regression and its eviction-disabled negative control passed
ten race-detector repetitions (15.582s). Both controls assert exactly two
accepted POSTs, so replay cannot satisfy the test. Existing active-stream
liveness, deadlines, missing-ACK, multiplexed cancellation, TLS, and proxy
tests passed under the race detector (6.279s).

The actual Claude CLI idle-turn probe passed (47.842s). It uses bare mode for
a focused transport test, accepts Claude's startup probes, verifies a real
quiet interval from persisted route timestamps, and requires both exact
user-turn markers with no failed or fallback routes. The broad matrix retains
normal Claude mode. This probe is now included in the real-provider gate.
Final complete gates and review must pass on the corrected source before tagging.

Review found a synchronization race in the new idle-pool fixture: a trailing
