## Release Preparation Evidence

On 2026-09-10, `make check`, `make test-cua-macos-fixture`, and
`make test-cua-docker-fixture` passed on the Linux VPS. The macOS helper result
is its portable protocol suite, not a native macOS build.
`goreleaser check`, `goreleaser release --snapshot --clean`, `actionlint`, and
`shasum -a 256 --check checksums.txt` in the snapshot directory passed.
Snapshot archives were produced for all four Linux/macOS architecture targets.
The release workflow now smoke-tests downloaded draft archives and verifies
their checksums and provenance on Linux and macOS before promotion.

`make test-live-fixture` passed (301.823s). The subscription-pool fixture
initially hit two timeouts during concurrent validation. Both failed cases
passed in isolation (7.261s), then the entire
`make test-live-subscription-pool-fixture` passed (25.499s).

The first PR CI run exposed Darwin's zombie-only process-group `EPERM`
behavior and a Linux migration test that ran before the user manager was
ready. Empty-group error handling now requires a successful observation with
no live members; actual permission failures remain errors. Linux CI checks
the user manager through D-Bus before running containment tests, and the
migration test explicitly requires a scope. Linux live job tests, including
mutation controls, passed after these changes (20.642s); actual Claude
detached-job lifecycle passed (11.680s). Native macOS CI confirmation is pending.

In [the next CI run](https://github.com/hishamkaram/claude-code-router/actions/runs/34476199971),
both macOS durable-job checks passed, including actual Claude completion and
cancellation. The explicit Linux scope probe exposed `NameHasNoOwner` on the
session bus. `systemctl --user` readiness was insufficient because it can use
systemd's private socket. CI now waits, bounded to 30 seconds, for
`busctl --user status org.freedesktop.systemd1` on the same session bus CCR uses.
No containment test is skipped or weakened.

The correction review found no actionable regressions. Its concurrent race
run hit the unchanged gateway idle-ping timing test; ten isolated repetitions
passed. The separate full `make check` run passed, including its race suite.

The initial configured real-provider run failed one exact response-marker
assertion for `litellm-grok-4-6` after completing the surrounding model-switch
turns. A full matrix rerun is required; this is not recorded as a pass.
