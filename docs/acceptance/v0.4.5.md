# CCR v0.4.5 Acceptance Criteria

This release fixes OpenAI-compatible handling of Anthropic assistant text
blocks with citation metadata. A checked item requires reproducible evidence on
the final release candidate; skipped live tests are not evidence.

## Behavior

- [x] Assistant text blocks with `citations` are accepted on the OpenAI Chat
  Completions conversion path.
- [x] Assistant text is preserved, while unsupported citation metadata is
  omitted from the downstream provider request.
- [x] The existing compatibility response header reports the exact ignored
  field marker `messages[].content[].citations`.
- [x] Multiple ignored-field markers are de-duplicated without hiding other
  compatibility degradation markers.
- [x] Unknown assistant fields remain rejected, as do citations or unknown
  fields in user, system, and tool-result text blocks.
- [x] Anthropic Responses conversion accepts citation-bearing assistant blocks
  and preserves their text.
- [x] A live Claude Code model switch proves citation-bearing assistant history
  no longer produces a 501 unsupported-content error.

## Privacy and Security

- [x] Citation contents are not forwarded to OpenAI-compatible providers after
  conversion; only the field-name marker is exposed in the response header.
- [x] No provider secret handling, persistence, or logging path was changed.
