# CCR v0.6.10 Acceptance

Scope: provide a convenient Linux installation path for CCR with checksum
verification, safe updates, explicit installation directories, and no implicit
profile or root changes. Unchecked publication items are not claims of
completion.

Evidence date: 2026-10-06.

## Feature evidence

- [x] The installer selects Linux amd64 or arm64, downloads the matching
  GoReleaser archive and `checksums.txt`, and verifies the archive SHA-256
  before extracting or replacing the installed binary.
- [x] The installer defaults to `~/.local/bin`, accepts pinned versions and
  explicit `--dir` destinations, and permits explicit system installs without
  requiring `HOME`.
- [x] Re-running the latest-release command updates an existing installation
  through a same-directory temporary file and atomic replacement; failed
  downloads, checksum validation, extraction, or installation leave the prior
  binary in place.
- [x] Invalid and incomplete options fail before network access, and the
  installer does not modify shell profiles or invoke `sudo` implicitly.
- [x] Deterministic installer tests cover latest and pinned URLs, amd64 and
  arm64 selection, updates, checksum failures, missing checksum entries,
  unsupported platforms, missing `HOME` with `--dir`, option-token values, and
  environments without `awk`.

## Known limits

The v1 installer intentionally supports Linux amd64 and arm64 only. macOS
continues to use Homebrew or manual release archives. Updates are explicit
re-runs of the installer; there is no background updater or implicit shell
profile mutation.
