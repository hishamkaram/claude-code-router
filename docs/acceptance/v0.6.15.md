# CCR v0.6.15 Acceptance Criteria

This release changes Claude workload environment inheritance. Checked items
require observed evidence. Pending publication items remain release blockers.

## Behavior and Privacy

- [x] Registered-provider environment names survive in Claude workloads and
  generic plugin hooks, MCP servers, and grandchildren. Original tests fail
  on baseline `21625c5`; the new implementation passes.
- [x] Foreground, print, managed-job and recorded-route resume paths pass live.
  Native ordinary settings environment precedence remains effective.
- [x] Explicit authentication/CUA-token controls and pool statusline isolation
  remain. Pinned resume credentials remain independent of provider mutations.
- [x] One typed overlay derives process environment and non-secret settings.
  Generated settings exclude credentials; synthetic values are absent from
  database artifacts and output. Boolean reports use private permissions.
- [x] Shell startup files are neither read nor sourced. Caller HOME, config
  directory, PATH and XDG values remain inherited; no user profile is replaced.
- [x] Lower project routing settings cannot bypass the gateway. A conflicting
  credential produces a visible native 401 event and zero upstream chat calls.
  The gateway response carries names-only guidance; Claude's display of that
  detailed response body is unverified.
- [x] Windows case-insensitive merging is covered by portable unit tests.
  Native Windows plugin execution is not claimed.

## Limits

Exported provider keys are available to trusted Claude tools/extensions, as
with plain Claude. File/keychain provider credentials remain inside CCR.
Compatible managed policy is required; managed routing conflicts and proxy
behavior are not solved here. Chat-only routes deliberately disable plugin
source discovery. Nested-session attribution and bare-mode lifecycle-hook
execution remain unverified. No new vision/CUA/executor capability is claimed.

Post-publication evidence will be appended after the exact-tag workflow,
draft verification and promotion complete.
