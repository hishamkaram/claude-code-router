# CCR v0.4.7 Acceptance Criteria

This release routes Claude Code auto-mode safety classifier traffic through the
active CCR alias for each Claude session. A checked item requires reproducible
evidence on the final release candidate; skipped live tests are not evidence.

## Behavior

- [x] Auto-mode classifier messages use the active startup or in-session CCR
  alias instead of the classifier's requested first-party model.
- [x] Auto-mode classifier token-count requests use the same active alias and
  do not mutate session model selection.
- [x] Active aliases are isolated by `x-claude-code-session-id`; one session's
  `/model` change does not affect another session.
- [x] A classifier request that explicitly names a valid CCR alias takes
  precedence over stale cached state and advances that session's active alias.
- [x] Missing or blank Claude session IDs are never persisted as a shared
  routing key.
- [x] Sessions with no active CCR alias retain intentional first-party routing.
- [x] Blocked, removed, invalid, credential-less, and provider-failing active
  aliases fail visibly without first-party Anthropic fallback.
- [x] Classifier detection accepts the current plain-string and structured text
  system forms without matching user content or mid-string marker text.
- [x] OpenAI Chat Completions, OpenAI Responses, and Anthropic-compatible
  routes preserve the requested response model while using the selected
  provider.
- [x] Route traces distinguish `auto_mode_classifier` and
  `auto_mode_classifier_count_tokens` without storing classifier bodies.
- [x] Live Claude Code CLI tests cover direct prompts, Agents, workflows, and
  an in-session `/model` switch with selected-provider classifier calls and
  zero unintended first-party classifier calls.

## Privacy and Security

- [x] No provider secret, classifier prompt, response body, authorization
  header, or raw session credential is added to logs or SQLite.
- [x] Existing keychain, environment, and provider authentication handling is
  unchanged.
- [x] Selected-alias failures cannot silently consume the preserved Anthropic
  subscription.
