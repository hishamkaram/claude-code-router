# CCR v0.6.13 Acceptance

Scope: raise the source and release Go minimum to 1.27.3, which includes the
standard-library fix for [GO-2026-6809](https://pkg.go.dev/vuln/GO-2026-6809),
and update compatible security tooling. Upgrade the indirect x/text dependency
to v0.41.0 (the minimum fix for GO-2026-6629 and GO-2026-5970) and its x/sync
requirement to v0.22.0 after the Windows binary scan identified affected symbols. Linter compatibility changes preserve
shutdown completion errors and flatten model-discovery assembly while preserving
model order, filtering, deduplication, response shape, and discovery errors.

reconstructs terminal redraws and waits for the current prompt and input echo
before submitting commands. All original model-list, route, response, and exit
assertions remain. The terminal emulator is a test-only dependency.

including native archive smoke tests. Pre-existing failures receive no exception.
