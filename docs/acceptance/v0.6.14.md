# CCR v0.6.14 Acceptance Criteria

This receipt covers repository security automation. It adds no application
protocol, routing, authentication, or computer-use capability. A checked item
requires observed evidence. Pending entries are release blockers where required.

## Protections

- [x] GitHub vulnerability alerts and automated security-fix PRs enabled.
- [x] Secret scanning and push protection enabled; private reporting preserved.
- [x] Automatic merging disabled. Dependabot configuration covers Go, Actions,
  and Docker with weekly routine updates. Local npm tooling manifests are
  excluded in `.git/info/exclude` and are not tracked application dependencies.
- [x] CodeQL reports all five configured languages successfully.
  Swift scanning pins macOS 26 and Xcode 26.6 and rejects unsupported compiler
  versions. GitHub documents that Swift 6.4/Xcode 27 tracing is unsupported:
  <https://github.com/orgs/community/discussions/210464>.
- [x] Dependency review is required and rejects new high/critical dependencies.
- [x] Main's ruleset requires CodeQL and blocks new high/critical findings.
- [x] OpenSSF Scorecard results publish and the public badge resolves.

Settings were changed through authenticated GitHub repository APIs on
2026-10-26. API readback confirmed the enabled protections; the dependency-graph
SBOM contained 60 packages and the initial Dependabot alert query returned no
open alerts. GitHub settings own enforcement; workflows own scan execution.
