# CCR v0.6.4 Acceptance

Scope: activate declared deferred tools after ToolSearch `tool_reference`
results on the OpenAI Chat Completions route, while preserving chronological
tool changes, visible unsupported-change handling, and provider-secret safety.
Unchecked publication items are not claims of completion.

Evidence date: 2026-09-18.

- [x] A request-conversion regression test proves that a declared deferred
  tool referenced by a `tool_result` is present in the upstream Chat
  Completions tool list.

  correct conversation order and does not replace the initially declared
  tools.
- [x] The live Claude Code + MCP image fixture asserts that a tool loaded by

## Known limits

The feature only activates references to tools that were declared in the
request. Unsupported or malformed tool changes remain visible compatibility
errors; this release does not silently map arbitrary provider-specific tools.
