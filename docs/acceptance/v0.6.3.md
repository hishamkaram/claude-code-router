## Known Limits

`cache_control` is provider-specific and is intentionally not forwarded to
OpenAI-compatible upstream APIs. Its omission is visible in the response
header. Other unsupported system-block fields and unsupported MCP tool
references remain explicit compatibility errors; this release does not broaden
those mappings.
