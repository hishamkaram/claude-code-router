# CCR v0.4.11 Acceptance

Date: 2026-09-06. Claude Code: 2.1.260. Platform: Linux.

## Contract

CCR consumes the first `--` in `ccr launch` and forwards the tail as Claude
Code arguments. Safety validation applies to the normalized arguments. A second
separator remains Claude Code's positional prompt boundary.

## Live Evidence

`TestLiveLaunchSeparatorOutputFormats` passed all four cases using the real
Claude Code subprocess with a deterministic OpenAI Chat fixture: JSON and
stream-json, each with and without the CCR separator. Every output record is
decoded as JSON, with successful result and assistant events asserted.

A freshly built `/tmp/ccr-separator` also passed all four cases against the
configured `glm-5-2` real provider. Input requested the single word `PONG` without
punctuation. JSON cases used plain stdin; stream-json cases used a JSON user
message and `--input-format stream-json --verbose`.

| Format | CCR separator | Events | First event | Assistant event | Exit |
| --- | --- | ---: | ---: | ---: | ---: |
| json | no | 1 | n/a | n/a | 16.30 s |
| json | yes | 1 | n/a | n/a | 16.61 s |
| stream-json | no | 14 | 5.59 s | 14.87 s | 18.28 s |
| stream-json | yes | 15 | 3.36 s | 10.64 s | 15.42 s |

All commands exited zero and returned a successful `PONG` result. The probe
decoded stdout separately from stderr and observed stream events as chunks
arrived, before subprocess completion. This proves incremental event delivery,
not a periodic heartbeat guarantee. The `unrecognized_model` telemetry appeared
on stderr in all four successful cases.

Representative commands (use an appropriate configured alias):

```bash
printf '%s\n' 'Reply with the single word PONG without punctuation' |
  ccr launch --model glm-5-2 -p -- --output-format json --max-turns 1
printf '%s\n' '{"type":"user","message":{"role":"user","content":"Reply with the single word PONG without punctuation"},"parent_tool_use_id":null}' |
  ccr launch --model glm-5-2 -p -- --input-format stream-json --output-format stream-json --verbose --max-turns 1
```

`ccr launch -- --help` and `-- --version` passed. Launches using an intentionally
missing alias and `-- --fallback-model sonnet` or `-- --bg` failed with the
expected policy rejection, before model lookup.

The first Codex review identified an existing live smoke test using the old
single-separator literal-prompt contract. Its invocation now uses two separators.
`TestLiveLaunchRoutesThroughFakeOpenAIProvider` and all four separator format
cases passed together after this correction.
