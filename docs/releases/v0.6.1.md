# CCR v0.6.1

## Mid-Conversation Tool Changes

CCR now translates Anthropic mid-conversation `tool_addition` and
`tool_removal` system blocks on OpenAI-compatible Chat Completions and
Responses routes. Tool-change control blocks are removed from translated
system text while neighboring text blocks remain in order.

Declared tools marked `defer_loading: true` stay unavailable until a matching
`tool_addition` or ToolSearch `tool_reference` appears. Removals and
re-additions are applied in
conversation order, and forced choices for unavailable tools fail visibly.
Simple `tool_reference` blocks are supported; MCP-specific reference types
remain an explicit compatibility boundary and return a visible
unsupported-reference error rather than being silently misrouted.

This follows Anthropic's [mid-conversation system message and tool change
contract](https://platform.claude.com/docs/en/build-with-claude/mid-conversation-system-messages).
See the [acceptance record](../acceptance/v0.6.1.md) for reproducible evidence
and release status.
