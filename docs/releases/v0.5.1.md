# CCR v0.5.1

Fix cancellation cleanup reporting on macOS and Linux hosts using the native
process-group fallback. After killing the owned group, CCR now waits within
the existing cleanup deadline for live members to disappear, avoiding survivor
reports caused by processes that are still exiting.

If the deadline expires, status preserves the latest successfully observed
survivors and explains the interrupted observation. Cleanup coverage remains
partial because escaped descendants cannot be excluded. Systemd scope behavior,
signal targets, and the CLI interface are unchanged.

The macOS computer-use helper remains an unsigned, source-built preview and
is not included in Homebrew or release archives.

```sh
brew upgrade hishamkaram/tap/claude-code-router
ccr version
```
