# CCR v0.6.9

This release adds local machine-readable discovery for agent integrations:

```sh
ccr --version
ccr model list --json
```

The model response has `schema_version: 1` and a sorted `models` array. Each row
contains the alias, provider, upstream model, compatibility, and effective
capabilities. An empty catalog is `models: []`. Listing does not launch Claude,
resolve credentials, or contact providers; it does not prove model availability.
Human-readable `ccr model list` and `ccr version` remain available.

Delegation Layer's companion `ccr:print` adapter uses foreground
`ccr launch --auth-mode provider-only` and owns its tasks' supervision and
continuation. It requires an explicit configured alias. CCR's interactive and
detached launch APIs are unchanged.

The live image fixture accepts Claude's optional image-source annotation while
still verifying the original image bytes. Agent-result fixtures distinguish
inherited tool history from the expected child response and accept native
SubagentHandback delivery acknowledgments. CI no longer builds CCR 0.5.1 for an
old-predecessor test; current CCR continuation and containment checks remain.
