# CCR v0.6.3

## Cached Tool-Change Compatibility

CCR now accepts Anthropic's `cache_control` hint when Claude Code attaches it
to a mid-conversation `tool_addition` or `tool_removal` system block. This
matches the existing handling for ordinary system text and prevents a valid
prompt-cache hint from turning an otherwise translatable request into a 501.

OpenAI Chat Completions and Responses routes drop the provider-specific hint
when translating the request and report that intentional degradation through
`X-CCR-Ignored-Anthropic-Fields: cache_control`. The strict allowlist remains
active: other unsupported top-level fields and unsupported tool references are
still rejected visibly.

See the [acceptance record](../acceptance/v0.6.3.md) for reproducible evidence.
