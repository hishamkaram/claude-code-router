# CCR v0.6.14

This release adds repository security automation without changing CCR's runtime
APIs or routing behavior.

Dependabot covers Go modules, GitHub Actions, and the managed-browser image
reference. GitHub dependency alerts and security-fix PRs are enabled, alongside
repository secret scanning and push protection. Dependency updates require
review and passing checks; automatic merging remains disabled.

CodeQL analyzes Go, browser JavaScript, Python, GitHub Actions, and the
source-built Swift helper. Dependency review and CodeQL merge protection block
new high/critical findings. Existing strict Go vulnerability checks and full
live release gates remain in place.

OpenSSF Scorecard publishes reports and a public README badge. Its numeric score
is advisory. The release workflow now grants publishing permissions only to
the jobs that need them.

These controls complement source review. Docker reference updates do not scan
the container's operating-system packages or Chromium for vulnerabilities.
The macOS helper remains a source-built, unsigned preview; it is not included
in release archives or Homebrew.
